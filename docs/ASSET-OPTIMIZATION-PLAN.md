# 웹 자산 경량화 계획

- 작성일: 2026-08-30
- 현재 트리 정리 완료: 2026-08-31
- 목적: 브라우저가 실제 표시하는 자산은 경량 WebP를 사용하고, 다운로드용 PDF와 실제 필요한 원본만 현재 트리에 유지한다.
- 원칙: 검수된 WebP 대체본으로 런타임 참조가 완전히 전환되고 사용자 승인을 받은 경우, 중복 PNG는 현재 트리에서 제거한다. 과거 파일은 Git 기록에서 복구할 수 있으며 인쇄 마스터·Affinity/TIFF 원본은 저장소 밖의 원본 보관 위치에서 관리한다.

## 경량화 전 기준

| 자산 묶음 | 기존 용량 | 주요 문제 |
| --- | ---: | --- |
| 한범수류 `viewer/` 북클릿 11장 | 약 187MB | 페이지당 약 11–20MB PNG |
| 한범수류 `web/` | 약 41MB | CD 라벨 16MB, HOME 배경 7.7MB |

다운로드용 PDF는 사용자가 명시적으로 다운로드할 때만 전송되므로 웹 경량화 대상에서 제외한다.

### 5. 폰트 중복 산출물

- 적용 완료 (2026-08-31): Vite의 `fontsource-woff2-only` 전처리에서 Noto Sans/Serif KR CSS의 구형 WOFF 대체 경로만 제외한다.
- WOFF2 744개, 기존 글꼴·굵기·Unicode 범위 744개를 그대로 유지한다. 가변 폰트로 교체하거나 글자를 부분 삭제하지 않았다.
- 폰트 빌드 산출물: 35,893,744 → 15,681,148바이트. 중복 WOFF 744개, 20,212,596바이트는 빌드에 포함되지 않는다.

- WOFF2 미지원 구형 브라우저에서는 CSS에 정의된 시스템 글꼴로 대체된다.

## 2026-08-31 현재 트리 정리

- WebP 대체와 런타임 전환이 끝난 중복 PNG **42개**를 현재 트리에서 제거했다.
- 구성: 한범수류 14개, 지영희류 6개, 공연 Viewer 9개, 공연 HOME·상세 배경 13개.
- 삭제 대상은 모두 대응 WebP가 존재하고 현재 런타임 경로가 WebP를 사용하도록 전환된 파일만 포함한다.
- 다운로드 PDF, WebP 대체본이 없는 이미지, 공용 인물 사진, 실제 런타임에서 여전히 쓰는 자산은 삭제하지 않는다.
- 이 정리는 현재 checkout/배포 자산의 중복을 제거하는 작업이며 과거 Git history 자체를 rewrite하지 않는다.

### 배경 파일 HTTP 전송 측정

- 대상: 정악 HOME desktop 배경 한 장. 원본 9,952,717 B → WebP 934,890 B.
- 조건: 로컬 프로덕션 미리보기(`127.0.0.1:4173`), curl, 다운로드 최대 2 MiB/s, PNG/WebP 교대로 각 3회. 브라우저 캐시를 사용하지 않았다.
- PNG 수신 시간: 4.884 / 4.840 / 4.813초, 중앙값 **4.840초**.
- WebP 수신 시간: 0.437 / 0.428 / 0.504초, 중앙값 **0.437초**.
- 재현: 빌드 및 preview 서버 실행 후 `node scripts/measure-background-transfer.mjs`.
- **이 수치는 한 파일의 전송 시간이다. 페이지 전체 로딩 시간, FCP, LCP, 모바일 실기기 측정치가 아니다.**
- 브라우저 연결의 제한된 검사 환경에는 Performance Timing API가 노출되지 않아 페이지 전체 로딩 시간 비교는 수행하지 못했다. 임의의 페이지 속도 개선율로 환산하지 않는다.

## 코드 연결 순서

1. 사용자 승인 아래 경량 파일을 기존 자산 폴더에 추가한다.
2. 픽셀 크기, 파일 크기, 알파 채널, 실제 화면 가독성을 확인한다.
3. `src/data/albums.ts`, `src/data/performances.ts`와 관련 CSS의 Viewer·texture·배경 경로를 새 파일로 변경한다.
4. 모든 런타임 참조가 사라지고 사용자 승인을 받은 구형 대체 파일은 현재 트리에서 제거한다.
5. HOME desktop/mobile, 앨범 3D, 북클릿 확대, 공연 Viewer를 각각 검수한다.
6. `npm run lint`, `npm run build`, `git diff --check`를 통과한 뒤 배포한다.

## 로딩 정책

- HOME의 닫힌 앨범 3D는 배경과 앞·뒤·세네카 texture만 로딩한다.
