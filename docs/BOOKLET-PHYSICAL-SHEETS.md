# 공통 북클릿: 종이 앞·뒷면 모델

2026-09-08 구현 기록. 적용 대상은 영산회상, 평조회상, 지영희류, 한범수류의 공통 3D 북클릿이다.

## 페이지 규칙

- 원본 `album.booklet.previewImages` 순서를 그대로 사용한다.
- 한 종이는 P1/P2, P3/P4, P5/P6처럼 홀수 페이지 앞면과 바로 다음 짝수 페이지 뒷면을 가진다.
- P1을 펼치면 왼쪽 P2 / 오른쪽 P3가 된다. P3을 넘기면 왼쪽 P4 / 오른쪽 P5가 된다.
- 제공된 마지막 페이지의 뒷면이 없으면 무지로 처리한다. 마지막 페이지를 복제하지 않는다.
- 모바일도 동일한 종이를 사용한다. P2 → P3은 펼침면 내 수평 이동, P3 → P4는 종이 넘김이다.

## 구현과 제거된 구조

- `bookletSheets.ts`: 페이지 짝, 읽기 위치, 텍스처 범위, 한 종이의 양면 형상과 두께 방향 계산.
- `PhysicalBooklet.tsx`: 동일한 종이 모델을 열기·닫기·정방향/역방향 넘김에 계속 사용한다. 양면은 같은 변형 좌표와 반대 면 방향을 가지며 뒷면 UV를 뒤집어 글자가 거울상으로 보이지 않게 한다.
- `BookletRig`: 앨범 내부에서 읽기 위치로 이동/복귀하는 동작만 조율한다. 페이지 모양을 다른 모델로 바꾸지 않는다.
- 기존 `BookletPages`, `TurningPage`, `MobileTurningPage`, 별도 표지/reader 모델과 `coverOpacity`/`readerOpacity` 교차 전환은 제거했다.
- 플레이어 모드로 전환할 때 북클릿 전체를 숨기는 처리는 유지한다. 펼침/접힘/페이지 넘김은 불투명한 종이로 처리한다.
- TRACKS에서는 디지팩이 뒤로 물러나며 축소되고, 공통 `PackageFade`가 외장과 북클릿 양면을 함께 페이드한다. 종료 임계값에서 재질 불투명도를 정확히 0으로 고정하고 디지팩 루트의 `visible`을 꺼 트레이·종이·그림자가 CD 구멍 뒤에 남지 않게 한다.
- 북클릿의 별도 플레이어 투명도 조작은 제거했다. CD는 장면에 분리되어 유지되며, 앨범 복귀 시 디지팩과 재질을 복원한 후 트레이로 돌아간다.
- 현재/인접 종이의 양면과 P1/P2만 제한적으로 로딩한다. 텍스처 준비 전에는 종이를 넘기지 않으며, 소유 컴포넌트가 사라질 때 자원을 정리한다.
- 재열기 시 첫 펼침면으로 초기화하고, 열린 북클릿의 장면 재부착을 정리해 컴포넌트 제거 후 별도 모델이 남지 않도록 했다.

## 확인 범위

- `npm run test:album`: 기존 오디오/디스크/렌더 정책 테스트 및 새 북클릿 테스트 7개.
- `npm run lint`, TypeScript 검사, 프로덕션 빌드.
- 로컬 내부 브라우저: 네 앨범 열기·페이지 넘김·복귀, 한범수류 P10/P11과 지영희류 P6/P7, 역방향 넘김 및 재열기.
- 모바일 390×844: 지영희류 P2 → P3 → P4 및 북클릿 접기. 확인 후 뷰포트 복원.
- TRACKS 보완: 전체 테스트 20개 통과. 네 앨범의 트랙 화면에서 CD 구멍 뒤 잔상 제거, 한범수류 앨범/북클릿 복귀 후 재진입, 지영희류 모바일 트랙 화면을 로컬 브라우저에서 확인했다.
- 전체 기기/브라우저, 실서비스 배포 검증은 포함하지 않는다.

## 변경 범위와 되돌리기

앨범 이미지 원본, 데이터, 공연 상세 콘텐츠는 변경하지 않는다. EXPLORE WORKS 선반 변경과 북클릿 변경은 별도 커밋으로 관리한다. 북클릿 PR만 되돌리면 이전 북클릿 구현으로 복귀할 수 있다.
